# Skill Man v0.1.0

把散落在不同智能体目录里的 Skills 收进一个技能库，阅读内容、查看来源，再按需分发。

1. **技能库**：按来源浏览 Skills，在应用内阅读 SKILL.md，并查看分发状态和文件健康情况。
2. **导入与仓库管理**：从 Git 仓库、本地文件夹或 ZIP 导入，按仓库管理版本和更新。
3. **智能体分发**：配置 Codex、Claude Code 或自定义目录，预览后分发到全局目录，也可以一次性分发到项目。
4. **macOS 界面**：支持简体中文、英文，以及随系统切换的浅色和深色外观。

## 安装

仅支持 Apple Silicon，要求 macOS 13 或更新版本。

下载附件中的 DMG，打开后将 Skill Man 拖到 Applications。此社区测试版使用 Ad-hoc 签名，未经 Apple Developer ID 签名或 Apple 公证，首次打开可能被 macOS 拦截。

确认来源可信后，先尝试打开应用，再进入「系统设置 → 隐私与安全性 → 仍要打开」。操作说明见 [Apple 官方文档](https://support.apple.com/en-us/102445)。组织管理的 Mac 可能不允许手动放行。

下载 DMG 和 SHA256SUMS 到同一目录，在该目录执行：

```sh
shasum -a 256 -c SHA256SUMS
```

## 测试版限制

- 应用通过 GitHub Releases 手动下载安装更新，不提供应用内自动更新。
- 项目级分发是一次性操作，后续由项目自行管理。
- 分发状态不代表智能体已经加载或执行了 Skill。
- 干净 macOS 用户环境下的浏览器下载、首次启动和手动放行仍需人工验收；构建检查不替代这项验收。

建议先用可备份的技能目录试用。遇到问题请在 Issues 中附上应用版本、macOS 版本和复现步骤。
