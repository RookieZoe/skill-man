# Skill Man v0.1.3

修复设置和应用更新弹窗中，更新说明与“手动下载”链接贴边、间距不一致的问题。帮助内容现在与弹窗正文对齐，说明、链接和底部操作区之间的间距保持一致。

本版沿用 v0.1.2 的更新公钥和数据格式。v0.1.2 用户可在应用内检查更新，确认下载并验签后，再次确认安装重启。真实升级与兼容版本手动回滚的验收结果由 [#107](https://github.com/RookieZoe/skill-man/issues/107) 记录；本发布说明不预先声明验收通过。

## 安装

仅支持 Apple Silicon，要求 macOS 13 或更新版本。

**v0.1.0 用户需要手动下载本页 DMG 并覆盖安装。** v0.1.0 没有更新公钥，无法通过应用内更新接入新通道；v0.1.2 是首个带公钥的基线版，v0.1.3 延续同一公钥。

打开 DMG，将 Skill Man 拖到 Applications。此社区版使用 Ad-hoc 签名，未经 Apple Developer ID 签名或 Apple 公证，首次打开或后续更新后可能被 macOS 拦截。

确认来源可信后，先尝试打开应用，再进入「系统设置 → 隐私与安全性 → 仍要打开」，随后重新打开应用。见 [Apple 官方说明](https://support.apple.com/en-us/102445)。组织管理的 Mac 可能禁止放行；不要关闭 Gatekeeper 或移除 quarantine 来绕过检查。

如需核对下载文件，将本页五个附件放入同一目录后运行：

```sh
shasum -a 256 -c SHA256SUMS
```

## 更新与验收状态

- 应用只接收正式 Latest，排除 Draft 和 Pre-release；不会自动下载或强制安装。
- 下载、验签或安装失败时，可从 [正式 Release 页面](https://github.com/RookieZoe/skill-man/releases/latest) 手动下载安装。
- 本版干净用户环境下的浏览器下载、首次启动与再次放行，以及两个真实版本间的升级、重启和 Manual App Rollback，仍需原生验收；构建成功不代表这些场景已通过。
- Manual App Rollback 仅指手动安装数据格式兼容的上一版，不降级数据库或恢复 Home 数据快照。

建议保留技能目录备份。遇到问题请在 Issues 中附上应用版本、macOS 版本和复现步骤。
