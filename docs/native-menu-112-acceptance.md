# #112 原生菜单组合验收

## 范围与证据来源

规格为 #108 / #114 的七项菜单决策，实施 #113 已关闭。基线 `7c4400d`（产品实现 `4b0bcb2`），Skill Man 0.1.3，macOS 26.6.2 / Apple Silicon。本轮补充验收测试，不修改产品行为，不发版。既有原生截图、构建及用户手工确认详见 [原生菜单验证历史](native-menu-verification.md)。

证据分别标记为真实原生对象测试、隔离行为测试、真实 App 操作、用户手工确认、静态路径检查。后两者不能替代未执行的自动化；内存或 API 测试不作为 鼠标、屏幕定位或实际网络观测的证据。

## 本轮可重复验证

- `cargo test --manifest-path src-tauri/Cargo.toml --test native_menu`：在进程主线程构建真实 Tauri/AppKit 菜单，覆盖三种语言选择 × 三种配色选择共九组。断言七项操作及分隔位置、更新/反馈文案、子菜单各三项且仅当前选择勾选。系统语言测试源固定为 en-US，另覆盖显式 en/zh-Hans。上下文无窗口、Home、Catalog、更新服务或生产插件；菜单构建前后两份临时偏好文件字节不变。该测试验证构建/读取菜单，不执行弹出菜单，不证明浏览菜单时所有进程 I/O 为零。初次日志 `/tmp/skillman-112-native-menu.log`；补强退出文案、分隔项及子菜单顺序断言后复测日志 `/tmp/skillman-112-native-menu-final.log`。
- `cargo test --manifest-path src-tauri/Cargo.toml --lib appearance_api`：五项真实临时 App-state 测试，验证持久化重开、合法/未知 legacy、原生选择优先、临时写路径故障、失败后重试、重复及并发选择。未改动用户偏好目录。日志 `/tmp/skillman-112-appearance.log`。

## 自动化边界与结论

CUA 已在此前实测中无法访问 SystemUIServer / Dock，App AX 没有托盘入口，工具不提供全桌面跨屏控制。这是当前验证能力限制，不是产品测试失败。用户询问这些项目能否自动完成时，已说明上述限制；没有将该询问当作通过确认。

#112 保持打开。剩余原生键盘、实际系统配色、不同缩放、浏览器反馈导航、窗口/Home 组合和菜单浏览调用观测需要补证。可以在完整桌面操作/观察能力可用时自动执行部分项目；当前不得以模拟输入、源码或原生对象构建替代。父规格 #108 不自动关闭。

## 剩余用户手工清单

已确认的托盘左右点击、普通子菜单/Esc/外部点击、Dock 两种偏好、双屏基础冒烟无需重复。

1. **键盘子菜单**：打开托盘菜单，用方向键进入语言/配色子菜单，按 Enter 选择；检查操作生效、仅一个勾选。
2. **窗口组合**：主窗口最小化后从托盘“打开”恢复并置前；退出后启动置前；主窗口隐藏时打开 About，只显示 About，不带出主窗口。
3. **语言同步**：在托盘和设置页分别切换简体中文/English，检查另一处同步、没有混合 App Copy，当前页面及输入保留。
4. **配色同步及系统响应**：在托盘和设置页分别切换浅色/深色，检查另一处同步；选择跟随系统后切换 macOS 浅色/深色，检查 App 跟随。
5. **问题反馈**：从托盘点击问题反馈，确认浏览器进入该仓库的新建 issue 页面（允许被重定向到模板选择或新建页面），不需要提交 issue。
6. **不同缩放与边缘**：在两块屏幕采用不同缩放设置时打开菜单及两个子菜单，确认靠屏幕边缘也完整可见、可选择；完成后恢复原显示设置。无法设置时记录环境不支持。
7. **主动更新组合**：分别在主窗口隐藏、最小化时从托盘检查更新；关闭自动检查后再次主动检查，确认独立原生窗口可见、请求不丢、不出现重复窗口且自动检查偏好未被改回。正常网络及网络不可用时均应有清晰结果，完成后恢复原偏好/网络状态。

写入失败/ReadOnly/HomeUnavailable 的原生提示与勾选还原、未挂载接收端/不支持更新的可控构建、菜单浏览期间零副作用调用观测，仍属于待补的隔离工程验证。它们不并入上述日常用户操作清单，不在用户真实数据目录注入故障，也不因日常手工清单通过而自动勾选。
