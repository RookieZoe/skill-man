# Library 文件管理器式选择

状态：Accepted

本决议取代 ADR-0009、ADR-0019、ADR-0021 中 Library Toolbar 临时多选模式与 selection shelf 的入口约定，不改变 Enable 的目标解析、预览确认或提交语义。

## 决议

- Library 不再提供批量操作入口、选择复选框、全选工具栏或批量启停操作栏。仓库管理、导入和其他操作流程的选择控件不受影响。
- 普通点击替换为单选；Command/Ctrl 点击切换该 Skill 的选中状态。选择按稳定 Skill ID 保存，不按显示名匹配。
- Shift 以最近一次普通或增减选择的选中项为锚点，选择到点击位置的连续区间。连续 Shift 保持锚点，可正向或反向扩大、缩小区间。
- 没有选中项时，Shift 从第一个可见 Skill 开始；锚点不可见时，以第一个可见选中项为起点，否则回退到第一个可见 Skill。范围严格按展开的来源及子分类显示顺序计算，不包含折叠的来源。
- 筛选切换清空选择；目录刷新移除不再存在的所选 ID。展开或收起来源本身不改变选择。列表内 Escape 清空选择，Enter/Space 支持与点击相同的修饰键。
- 多选时详情区显示数量及堆叠卡片，仅最上层展示摘要，底层最多两个不可交互的轮廓，不加载多份正文。
- 右侧统一为“技能分发”，单选和多选共享目标组布局。项目分发入口移至面板标题旁；单选的移除资格不变，不提供批量移除。
- 多选按目标组汇总 `desired` 为 `DistributionState`：全部为真显示“已分发”并开启开关；全部为假显示“未分发”并关闭；部分为真显示“部分分发”并关闭。关闭态点击以全部选中 Skill 进入既有 Global Enable 预览确认，不自动覆盖冲突；项目分发复用多 Skill 的 Project Enable 计划。分发状态不代表 Agent 已加载或执行技能，链接健康独立展示。
- “已分发”开关关闭后的批量撤回沿用既有批量 Disable 实现：仅处理所选目标组，逐 Skill 重新获取 lifecycle plan 并校验后提交、finalize；遇到失败立即停止，明确报告完成数量并刷新状态，不承诺批次原子性。这是 ADR-0019 不增加批量 Disable 的操作面例外，Core ownership 与 WriteGate 检查不变。不提供批量 Repair。

## Consequences

选择与执行操作解耦。单项操作、仓库级操作及 Core 安全边界保持不变；选择多个 Skill 本身不产生任何持久化写入。
